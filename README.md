# The Freshy Clinic

เดโม่ระบบหลังบ้าน รองรับมือถือ iPad และ PC โดยยึดรูปแบบบัตรลูกค้า ประวัติซื้อ แบบฟอร์มขาย และ Sale Pitch / Follow up ของระบบคลินิกเดิม

## ขอบเขต

- ภาพรวม: ยอดขาย รับเงินจริง ค้างชำระ และลูกค้าที่ซื้อ
- ข้อมูลลูกค้า: เพิ่ม/แก้ไข ค้นชื่อ OPD เบอร์โทร เตือนเบอร์ซ้ำ บัตรประวัติและยอดสะสม
- การขาย: หลายสินค้า ส่วนลด ระบุเซลและสาขา มัดจำ รับชำระส่วนที่เหลือ ยกเลิกและคืนเงินพร้อมเหตุผล
- ยอดรายเซล สาขา การติดตามลูกค้า รายงาน และส่งออก CSV
- ตั้งค่าพนักงาน สาขา รายการบริการ ตัวอย่างสิทธิ์ และประวัติการแก้ไข

เดโม่นี้ใช้เฉพาะข้อมูลสมมติ เก็บการเปลี่ยนแปลงใน localStorage ของเบราว์เซอร์เครื่องที่เปิด ไม่มีการซิงก์ข้อมูลข้ามเครื่อง และยังไม่มีการล็อกอินหรือตรวจสิทธิ์จริง ห้ามใช้เก็บข้อมูลลูกค้าจริง บทบาทที่หน้า “สิทธิ์ผู้ใช้” เป็นข้อเสนอหน้าจอเท่านั้น

ยอดขายนับตามวันที่ขายและไม่รวมบิลยกเลิก ส่วนรับเงินจริงนับตามวันที่รับเงิน หักคืนเงินตามวันที่คืน ตัวกรองสาขาอ้างอิงสาขาที่ขาย เซลเจ้าของยอดผูกกับรายการขาย ไม่ใช่ผู้ดูแลลูกค้า ยอดค้างชำระรวมทุกวันของสาขา/เซลที่เลือก ส่วนประวัติรับเงินระบุสาขาที่รับเงินแยกไว้ด้วย

## Supabase

เตรียม schema `freshy_clinic` ในโปรเจกต์ SUMOWEB โดยแยกจากตารางเดิมทั้งคลินิก เว็บไซต์ และเกม มี 9 ตาราง: branches, staff, customers, products, sales, sale_items, payments, followups, audit_log

ทุกตารางเปิด RLS และเพิกถอนสิทธิ์ browser roles (`anon`, `authenticated`) รวมทั้งไม่มี policy ที่เปิดให้เข้าถึง จึงอยู่ในสถานะ deny-by-default โดยตั้งใจ หน้าเดโม่ยังไม่เชื่อมฐานข้อมูลนี้ ไม่มีคีย์หรือ credentials ในรีโป ขั้นระบบจริงต้องเพิ่มการผูกบัญชี สิทธิ์รายสาขา และธุรกรรมฝั่งเซิร์ฟเวอร์สำหรับยอดเงินก่อนเปิดการเข้าถึง

`supabase/schema.sql` เป็นสำเนาโครงสร้างที่สร้างแล้ว ไม่ใช่สคริปต์ให้รันซ้ำบน schema เดิม

## ตรวจสอบ

ใช้ Node.js 22 ขึ้นไป ไม่ต้องติดตั้ง dependency

```sh
npm test
npm run check
```

## เผยแพร่

โค้ดหน้าบ้านอยู่ที่ `index.html` และ `assets/` รองรับ GitHub Pages โดยตรง ตั้ง Settings → Pages → Source เป็น GitHub Actions แล้ว workflow `Deploy demo` จะตรวจสอบและเผยแพร่เฉพาะสองส่วนนี้

โครงสร้างเดโม่เป็น HTML/CSS/JavaScript ไม่มี Flask ข้อมูลสาขา พนักงาน ราคา และลูกค้าทั้งหมดในเดโม่เป็นข้อมูลสมมติ
